# 2025_munzip_title_text_ver(2) — 한국문집총간 한시 2025판 속편 (#0664~#1259)

## 파일과 형식

- 파일명은 `0NNN.문집명.txt`다. 파일 순서가 곧 문집총간 순서다. 2024년판 파일이 없던 문집은 여기에도 없다.
- 인코딩은 UTF-8(BOM 없음), 줄바꿈은 LF다. 마지막 행 뒤에 개행이 있고 빈 행은 없다.
- 행 형식은 `<title>제목</title>,<text>본문</text>`이다. 본문의 구(句)는 `。`로 끝나고 다른 문장부호는 없다.
- 제목·본문 규칙(연작 `其N`, 小題·韻 표지, 원주·序 삭제, 결자 `𪚥`, 결락 표시 보존 등)은 본편 README와 같다.
- `bigram_code.ipynb`는 예전에 올린 분석 노트북이다(데이터 아님).

### 2026-09-15 — 속편 정련·검수본 공개 (218,960수, #0801까지 확인)

### 2026-09-24~28 — #0802~#1259 시 형태 검증

- #0802~#1259는 정련 때 XML에서 통째로 다시 만들어 사람 눈이 가지 않은 구간이었다. 수가 흔들리면 수 단위로 붙일 작자·주석이 모두 어긋나므로, 형태부터 봤다.
- 검증 대상 좁히기: 처음 11,335수에서 규칙상 불규칙이 당연한 것을 빼고 1,289수로 좁혔다. 뺀 것은 다음과 같다.
  - 40구를 넘는 장편 고시.
  - 辭·賦·其他類.
  - 附·元韻·`次` 표지가 붙은 것(기사가 따로 없는 게 당연함).
  - 짝수구 5·6·7언 정형(육언 포함).
- 확인 방식: 연구자가 검증 화면을 #0802부터 #1259까지 순서대로 모두 봤다. 무응답은 정상이고, 이상한 것만 `ㄴ`(나눔)·`ㅈ`(시 아님)·`?`로 표시했다.
- 결과로 고친 것:
  - 본문 보정 284행: XML 대조 162, 압운 검증 63, 연구자 지시 52 등.
  - 제목 보정 98행: 대부분 序를 빼면서 연작 번호를 당긴 것.
  - 시가 아닌 행 100개 삭제: 祭文·啓·序·策과 연작 속 序·주석.
  - 한 행에 여러 수가 붙은 9행을 30수로 나눔.
- 이 과정에서 정한 원칙:
  - 구 경계가 밀린 것은 압운으로 검증되는 경우에만 고친다. 운서에 없는 글자가 섞이거나 한 운목에 들지 않으면 손대지 않았다(26수).
  - 교감주의 衍文·결구는 교감주를 따른다(송파집 「賑廳恤飢民」 其四 — 衍文 두 자를 빼고 빠진 구를 `𪚥` 다섯으로 세움). 衍文 교감주는 전수 28건인데, 시에 걸린 11건 가운데 형태가 깨진 것은 이 하나였다.
  - `N字缺`은 결자 `𪚥` N개로 적는다.
  - 序·주석을 연작에서 빼면 뒤 수 번호를 끝까지 하나씩 당긴다.

### 2026-09-28 — 전 구간 보정(본편과 공통)

- 번역원이 詩類 밖으로 분류한 시를 넣었다(속편 +64행, 21종).
- 한 행에 두 수 이상이 붙은 것을 나눴다(속편 87행을 나눠 +109행).
- 본문 전각 부호를 지우고 호환 한자를 NFC로 맞췄다.
- 수북정집의 첫 구 결락 3행을 XML의 `<원주>缺</원주>`대로 `缺。`로 되살렸다.
- 옥수집 「題淸愛堂帖」 三首를 XML 단락대로 칠언절구 3수로 되살렸고, 其三이 「次海藏侍郞洞陰軸中韻」 뒤에 놓였던 순서를 바로잡았다.
- 자세한 것은 본편 README의 진척 기록에 있다.

행 수 변화 +88의 내역: 보충 +64, 분절 +109, 시 아닌 행 삭제 −100, 9행→30수 나눔 +21, 그 밖의 중복·주석 삭제 −6.

### 2026-09-29 — 행 순서를 XML 기사 순서로 맞췄다(본편과 공통)

- 행 순서가 대응 기사의 순서를 거스르던 것을 기사 순서대로 옮겼다. 행 내용과 행 수는 그대로다.
- 속편에서는 해장집(#1209) 4행의 자리가 바뀌었다. 같은 시가 XML에 두 번 실린 척암집 「感歎」·직재집 「贈金景先」은 옮기지 않았다. 자세한 것은 본편 README에 있다.
