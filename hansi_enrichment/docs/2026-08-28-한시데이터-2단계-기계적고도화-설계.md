## 4. 판정 규칙

### 4.1 Charactercount
- 각 `<Line>` 텍스트(태그 제거)의 한자 수. 최빈값 채택.
- 최빈값 비율 < 80% 또는 행 길이 종류 ≥ 3 → `불규칙`.
- 5→오언, 6→육언, 7→칠언, 그 외 → `불규칙`.
- 기존값과 다르면 교정하고 `flags`에 `(문집, id, 기존→신규)`.

### 4.2 Basetype/Detailtype
0. 행수 n, 행길이 균일 여부 u, 운자들의 성조(측성운 포함?), 압운 운목 집합.
1. **고체 신호**: 행길이 불균일 / n ∉ {4,8,12,16,20,24…짝수} / 측성운 / 압운이 통운 범위를 벗어난 복수 운목 / n 홀수.
2. 고체 신호 하나라도 → `Basetype=고체시`. Detailtype: 제목·구조로 `부(賦)`/`사(辭)`/`사(詞)`/`악부`/`잡체시`/`과체시` 판별 가능하면 그것, 아니면 `고시`.
   - 제목 끝 `賦`→부, `辭`→사(辭), `詞`→사(詞), `行/歌/引/吟/謠`→악부(고시로 보수적 처리 가능), `~體`→잡체시.
3. 근체: n=4 → `절구`, n=8 → `율시`, n>8 짝수 → `배율`.
4. 경계 사례(예: 4행인데 측성운, 8행인데 통운 이탈)는 판정 후 `flags`에 `form_uncertain`.
5. 골드에 Basetype/Detailtype가 있으면(임백호집) **신뢰**하고 대조만.

### 4.3 rhyme
0. 스테이지 30에서 Form 확정 후 실행.
1. 압운행 결정:
   - 근체 절구/율시/배율: 짝수행 전부. **1행**: 말자가 평성이고 짝수행 운목/통운과 같으면 수구압운 → 태깅.
   - 고체: 말자 운목이 직전 압운행과 같거나 통운이면 압운행. 운목이 바뀌면 환운 지점으로 표시(`flags: rhyme_change`).
2. 압운행의 말 한자에 `<rhyme>` 부여. 그 한자가 기존 `<term>`/`<d>` 요소의 마지막 글자면 **그 요소 내부**에 삽입(`…字<rhyme>末</rhyme></term>`). 아니면 bare `<rhyme>末</rhyme>`.
3. 기존 `<rhyme>`가 압운행이 아닌 곳에 있으면 제거(`flags: rhyme_removed`).
4. 평수운에 없는 운자(벽자) → 유지 + `flags: rhyme_char_unknown`.
5. (옵션) `<rhyme rhyme="東">` 처럼 운목 속성 부여 — 매뉴얼 로드맵. 1차엔 flags/리포트에만.

### 4.4 Couplet
- 근체 율시(n=8): 3·4행, 5·6행을 각각 `<Couplet><Line…/><Line…/></Couplet>`.
- 근체 배율(n>8): 1·2행과 마지막 2행을 제외한 모든 인접 짝을 Couplet.
- 대장 성립 여부는 판단하지 않음(구조만). 기존 데이터에 `<Couplet>` 없음(1단계 lint 확인).
- 절구·고체는 Couplet 없음.

### 4.5 Themes 스키마
- `<Themes>` 안의 `<Main>`, `<Sub>`, 그리고 `category="영문주제명"` 같은 **템플릿 스텁 `<Theme>`** 를 모두 제거.
- 실제 값이 채워진 `<Theme category="…">`(스텁 아님)는 **보존**.
- 결과: `<Themes></Themes>` 또는 유효 `<Theme>`만 남김.

### 4.6 term 감사 (리포트 전용)
- 각 `<term>X</term>`: 내부 `<rhyme>` 제거한 X.
- `len(X)==1` → `term_single_char`
- `len(X)>=2` and X ∉ 한어대사전 → `term_not_in_dict`
- 문집별·유형별 집계 + 상위 사례. **수정 없음** (3단계/검수 인계).

| 차원 | 착수 기준선(왕예本 대비 골드) | 2단계 목표 |
|---|---|---|
| Charactercount | 측정 | ≥ 99.5% 일치, 나머지 flags |
| Basetype | 왕예本 111개만 채움 | 골드 대비 ≥ 97% |
| Detailtype | 〃 | ≥ 96% |
| rhyme | 왕예本 precision 낮음(과다) | 골드 대비 재현율 ≥ 0.97 **且** 이론 정합(시별 단일 운목/통운, 근체 짝수행 전수) 100% |
| Couplet | 없음 | 율시·배율 구조 100% |

골드 rhyme는 불완전(시어 태깅 부산물)하므로, rhyme는 **골드 일치 + 이론 정합**을 병행. 이론 정합 위반이 골드 일치보다 우선.
