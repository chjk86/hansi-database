# 한시 데이터 고도화 — 3단계 파일럿 설계

작성일 2026-08-28 · 상태: **완료** — 파일럿(§8), 권고(§9), Themes 18문집 확대(§10) · 선행: [2단계](2026-08-28-한시데이터-2단계-기계적고도화-설계.md)

## 1. 목표

판단 영역 3차원(**term/d 재분절 · Themes 26분류 · 전고 Allusion**)을 **고죽유고 245수**에 파일럿 적용.
방법 검증 오라클 = 임백호집 3차완본(3차원 골드 완비: term 6,775·d 4,473, Theme 1,188, Allusion 215).
성공 시 나머지 문집으로 확대.

판정 엔진: **이 세션의 Claude** (규칙·시소러스로 후보를 좁힌 뒤 Claude가 최종 판정 + evidence 추출). 외부 API 불필요.

## 2. Themes

### 2.1 방법
1. **시소러스**: 임백호집 골드 `<Theme category basis evidence>`에서 category별 title어·term어 가중치(df·idf) 추출. (`themonto.Thesaurus`)
2. **후보 스코어링**: 고죽유고 각 시의 제목 n-gram + 본문 시어(`<term>`/`<d>`) + 본문 2-gram → category 점수. 상위 5 + 매칭어.
3. **Claude 판정**: 시별 (제목·전문·후보 category+매칭어) → 적용 category 다중선택(평균 1.6개) + `basis`(title/term/"title, term") + `evidence`(title:漢字 / term:시어).
4. `<Themes>` 채움.

### 2.2 검증 (임백호집 k-fold)
- 순수 시소러스 baseline: top2 정밀도 0.56 / 재현율 0.48 (약함 — 후보생성용).
- category별 재현율 편차: donate·buddhism·farewell·sympathy·frontier 0.87~0.96 / structure·meet·taoism·season 0.38~0.65.
- **Claude 판정 검증**: 임백호집 40수 홀드아웃(시소러스는 나머지 683수로) → Claude 판정 → 골드 대조. 목표 정밀도·재현율 ≥ 0.80.

## 3. term/d 재분절

### 3.1 방법
1. 2단계 감사 결과(고죽유고: 1글자 term 4, 사전미등재 49) + 절주 규칙:
   - 5언 → 2·3, 7언 → 2·2·3. `<term>`/`<d>` span이 절주 경계를 넘으면 의심.
   - 매뉴얼 부정어 규칙(無消息·不同·未歸 = 태깅 / 不敢·莫道·何必·不知(7구 첫머리) = 제외).
2. **의심 span 목록** → Claude 검토: 유지 / 분할 / 병합 / d로 강등 / 태그 제거.
3. 사전 조회(한어대사전)로 term/d 재확정.
4. **매뉴얼의 "한어대사전 용례와 명백히 다르면 d 재태깅"은 미채택** (사용자 결정). 사전 유무만.

### 3.2 검증
- 고죽유고는 골드 없음 → 임백호집으로: 골드 term/d에서 무작위 200개 span을 인위 손상(경계 이동·term↔d 뒤집기·삭제) → 감사+Claude가 복원하는지.
- 목표: 손상 탐지 재현율 ≥ 0.85, 정상 span 오탐 ≤ 5%.

## 4. 전고 (Allusion)

### 4.1 방법
1. **탐지**: Claude가 시 전문을 읽고 典故 사용 행 식별 → target 구(句/어).
2. **분류**: 7부 (A경 B사 C자 D집 E도 F불 G기타).
3. **출전 추출**: source(문헌)·chapter(편)·originaltext(인용문). 한어대사전 표제어 뜻풀이의 인용 서지로 교차확인.
4. `<Line>` 내부에 `<Allusion target type source chapter originaltext/>` 삽입 (매뉴얼 형식).
5. **불확실 건은 `제안` 표시** — 1차엔 검수 인계. 자동 확정 아님.

### 4.2 검증 (임백호집)
- 골드 215 Allusion 제거 → Claude 탐지 → 대조.
- target 구 재현율(부분일치 허용) ≥ 0.6, type(7부) 정확도 ≥ 0.7, source 정확도 ≥ 0.5. (전고는 본질적으로 어려움 — 낮은 목표.)

## 6. 실행 순서

1. Themes 시소러스 + 후보 배치 생성
2. 임백호집 홀드아웃 40수로 Claude 판정 검증 → 목표 미달 시 시소러스·프롬프트 조정
3. 고죽유고 245수 Themes 판정 (배치 ~20수)
4. term/d 손상복원 검증 → 고죽유고 의심 span 검토
5. 전고 탐지 검증 → 고죽유고 적용
6. `3_pilot_고죽유고.md` 종합 → 사용자 검수 → 확대 여부 결정

## 7. 리스크

1. **Claude 판정 일관성**: 배치마다 기준 흔들림 → 프롬프트에 26분류 정의(주제매뉴얼) + 판정 규칙 고정. 배치 크기 ≤ 20.
2. **전고 정밀도**: 낮을 것으로 예상 — "제안" 표시로 검수 부담 관리. 목표를 보수적으로.
3. **고죽유고 검증 부재**: term/d·전고는 임백호집 대리 검증만. 고죽유고 산출은 육안 표본검수 필수.
4. **확대 비용**: 18,000수를 Claude 배치로 = 900+ 배치. 파일럿 성공 후 엔진(계속 Claude / Gemini / 임계값 이상만) 재결정.

### term/d — 자동화 불가
| 방법 | 절주규칙(5언 2·3, 7언 2·2·3) + 사전 조회 + 부정어 규칙 |
| 검증 (임백호집 골드 span 인위 손상 581건) | **손상 포착 0.31** · 정상 span **오탐 32%** |

사전 미등재는 모든 `<d>`(정의상) + 관습 시어라 신호가 안 됨. 절주횡단도 유효 시어가 다수. → **규칙 감사 무효**. `1글자 term`(고죽유고 30건)만 약한 신호이나 매뉴얼이 1자 시어 허용. **term/d는 검수 영역**으로 확정, 자동 개입 없음.

### 전고(Allusion) — 제안만 가능
임백호집 골드 215건 표본 검토: 유명 전고(獬豸冠·五馬·燕子樓·三靑鳥·班超·懸榻·豊城劍氣)는 target·대략적 source 식별 가능. 그러나 벽전고(葯房→湘夫人, 高山十二郵→輿地勝覽, 非夫→左傳 특정편)는 놓치고, chapter·originaltext 정밀도 낮음. 허위 전고 생성 위험 미측정. → **자동 확정 불가. "제안" 표시 후 검수** 만 현실적.

## 10. Themes 확대 (2026-08-28, 18문집)

파일럿 성공 → 전 문집 자동채움. 배치 판정 대신 **auto tier** 도입:

## 11. Themes 방식 개정 — 제안 + 확신도 (2026-08-28)

Option B(고신뢰만 자동채움)는 분류율이 36%에 그쳐(신호 약한 즉경·술회·영물시 다수), **거의 전 시에 주분류 제안 + 확신도** 방식으로 전환.

- `scripts_3_themes/30_suggest.py` + `lib/hansi/themconf.py`
- 확신도(0~100) = 시소러스 점수비·절대점수·title_hit 로그 스케일. `次韻`·`贈別`·`送+사물`·악부제·제영 제목은 보정.

## 12. term/d 재태깅 (2026-08-28) — 방법 확보

§8의 "term/d 자동화 불가"는 **감사(audit)** 방식(기존 태깅에서 오류 탐지) 기준. **재태깅(어휘 사전 기반)** 방식은 가능함을 확인.

**발견**: 대상데이터 4문집(기재집·동명집·동악집·현주집)은 수작업이 아니라 **사전 bigram 무차별 자동태깅** — 태깅률 58~68%, `<d>` 0개, 부정어구(不苦·無以)까지 태깅.

**방법** (`scripts_3_themes/40_termd.py` + `lib/hansi/termdtag.py` + `assets/d_lexicon.txt`):
- 사전(한어대사전) bigram → `<term>`
- **d-어휘** = 수작업 태깅 문집(임백호집·Drive 15) term/d 중 사전 미등재 2글자, 2회+ 출현 (1,845개) → `<d>`
- 부정어구(`不/無/未/莫/勿/非/休/何/豈/寧` + 동사, KEEP 예외 제외) 제거
- 절주·`<rhyme>` 위치 보존

| | 값 |
|---|---|
| 임백호집 골드 대비 토큰 | **P 0.85 · R 0.82 · F1 0.83** |
| term/d 규칙 준수 | 100% (term=사전O, d=사전X) |
| 미해결 | 1글자·3글자+·lemma(~17% 오차) → 검수 |

**적용 범위 — 시(詩) 단위 판정**: `<d>` 태그가 있으면 작업자 수작업으로 간주 → 유지. `<d>` 없으면 사전 bigram 무차별 태깅으로 간주 → 재태깅. (골드 임백호집 723수 중 `<d>` 없는 시는 2수뿐 = 신뢰도 높은 신호.)
- **재태깅 13,151수**: 대상데이터 4문집(8,200) + Drive 15문집 중 자동태깅 상태(호음잡고 2,345·소재집 1,243·성소부부고 307·손곡시집 282 등 ~4,950)
- **수작업 유지 4,361수**: `<d>` 있는 시 (옥봉집 503·용재집 595·지봉집 432·고죽유고 243 등)

3단계 최종: **Themes 제안+확신도(89%) + 대상데이터 4문집 term/d 재태깅(F1 0.83)**. 나머지 term/d·전고는 검수.
