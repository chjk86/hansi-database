한국고전번역원 한국문집총간 정편(350책 663종, 고전종합DB `ITKC_MO_0NNNA`)의 詩類 기사를 **한 행에 한 수**씩 담은 텍스트판이다. 9세기 최치원 『계원필경집』(#0001)부터 20세기 초 曺兢燮 『암서집』(#0663)까지 고려·조선 문집의 한시 전체를 다룬다. 속편(#0664~#1259)은 `../2025_munzip_title_text_ver(2)/`에 같은 형식으로 있다.

**#0001~#0663 전 구간을 연구자가 확인한 자료다**(2026-09-15). 속편은 #0801까지만 확인이 끝났으니 두 폴더를 합쳐 쓸 때 속편 README의 확인 범위를 본다.

## 시형 분포

구(句) 길이가 모두 같은 행을 언(言)으로, 구 수로 절구·율시를 나눈 것이다. 압운·평측은 보지 않은 형태 분류다.

- 100구 이상인 긴 시가 966행, 본문 최장 7,151자. 한 구뿐인 행 99개는 逸句·斷句다.

## 파일과 형식

- 파일명 `0NNN.문집명.txt` — NNN은 문집총간 번호(= ITKC id `ITKC_MO_0NNNA`). 파일 순서가 곧 문집총간 순서이고, 파일 안 행 순서는 고전종합DB 기사 순서다.
- 인코딩 UTF-8(BOM 없음), 줄바꿈 LF, 마지막 행 뒤 개행 있음, 빈 행 없음.
- 행 형식: `<title>제목</title>,<text>본문</text>`. 본문의 구는 `。`로 끝나고 다른 문장부호는 없다.

```
<title>次寄姜復泉子久 鶴年</title>,<text>遷次君無宅。懷安我有居。何時山水處。高棟接茅廬。</text>
<title>次寄姜復泉子久 鶴年 其二</title>,<text>西塞軍麾滿。生靈未奠居。風塵無息日。吾敢愛吾廬。</text>
```

## 제목

- 연작(連作)은 `제목`, `제목 其二`, `제목 其三` … 로 한 수씩 나눈다. 첫 수에는 번호가 없다. 원문의 `又`도 `其N`으로 통일했다. 숫자는 모두 한자(`其十二`).
- 제목 뒤 한 칸 띄어 붙은 것(110,522행)은 세 가지다. ① 小題(DB `<단락제목>`): `T 小題`, 이어지는 무제 수는 `T 小題 其二`. ② 제목 원주(작자 자주): `次寄姜復泉子久 鶴年`. ③ 단락 끝의 韻 표지 원주 `原韻`·`次韻`·`右次○○韻`: 남의 原韻·次韻 수를 문집 저자의 시와 구별하기 위해 제목 뒤로 옮겼다(`T 原韻`).
- `[ ]`(6,132행)는 고전종합DB 편자가 보충한 제목이다.
- 제목 길이 중앙값 9자, 최장 876자(긴 序가 제목에 붙은 경우).

## 본문

- 본문 원주(原註), 서문·발문, 挽詞의 대상 표기 같은 산문 단락은 삭제했다. 賦·辭·操처럼 기사 전체가 산문형인 것은 그대로 두었다.
- 결자(몇 자인지 아는 빠진 글자)는 `𪚥` 한 글자로 통일했다. 원자료의 `▦`·`▣`·`□`·`■`·글자 이미지·`N字缺`이 모두 여기에 든다. 유니코드에 없는 글자도 `𪚥`.
- 몇 자가 빠졌는지 모르는 결락 표시 `缺`·`以下逸`·`以下佚`·`下失`·`本文缺`는 원문 그대로 둔다. 한 수가 통째로 없어져 `逸`·`佚` 한 글자만 남은 행도 그대로다.
- 국문 시조·가사(불우헌집 賞春曲, 농암집 漁父歌 등)는 詩類 기사에 실린 대로 두었다. 옛한글은 사용자 영역(U+E000~) 코드다. 한시 통계에서는 한글 포함 행을 제외한다.
- 聯句의 작자 표지(`秀。`·`直。`)는 본문에서 지웠다. 聯 제목 시는 공동작이므로 작자별 분석에서 따로 다룬다.
- 본문 안의 공백은 지웠다. 남아 있는 공백은 국문 시가 행과 결락 표시 앞뒤뿐이다.
- 호환 한자(U+F900대)는 NFC로 통합 한자에 맞췄다. 그 밖의 이체자는 원문대로다.

## 작자

- 시의 작자는 문집 저자와 다를 수 있다. 附錄의 輓詩·祭文, `原韻`·`次韻` 표지가 붙은 남의 시, 聯句의 공동작이 그렇다. 파일 단위로 작자를 붙일 때는 이 행들을 걸러야 한다.

## 만든 과정

2024년판(기사 단위)에서 출발해 통파일 분할 → 마커·운자·점법 기반 연작 분리 → 고전종합DB 공식 XML(공공데이터포털 마스터 데이터셋)로 재생성 → 제목·번호·표지·결자 정리 → 정합성 검사·XML 대조 → 연구자 전 구간 검수 순으로 만들었다. 결정 근거·규칙·수치·검증 기록과 정련 스크립트는 작업 저장소에 있으며 이 폴더와 함께 공개하지 않았다.

## 알려진 한계 (2026-09-15)

- 같은 시가 두 번 실린 행(원자료 중복 포함)과 같은 본문에 다른 제목이 붙은 쌍이 소수 남아 있다.
- 공식 XML 자체가 한 수를 둘로 나누거나 序를 시로 둔 곳은 XML을 따르지 않고 원래 행을 두었다.
- 글자 차이(판본 차이, 결자 복원)는 손대지 않았다. 원문과 한두 글자 다른 행이 있다.
- 시형 분포는 구 길이만 본 것이라 근체·고체 구분이 아니다.
